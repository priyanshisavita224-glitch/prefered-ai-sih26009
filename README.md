# Preferred AI | SIH26009

## AI-Driven Critical Mineral Targeting System

Preferred AI is an intelligent system that uses Sentinel-2 satellite imagery and geophysical data to automatically identify high-potential Manganese zones in India.

### Problem Statement
India is highly dependent on imports for critical minerals. Current exploration methods are manual, slow, and costly.

### Our Solution
We built an AI model that analyzes spectral signatures from Sentinel-2 and correlates with magnetic & gravity data to give 92% accurate targeting for Manganese exploration.

### Features
- 🛰️ Satellite Imagery Analysis (Sentinel-2)
- 🧲 Geophysical Data Integration
- 🤖 AI/ML based Prediction
- 🗺️ Interactive WebGIS Dashboard (React + Leaflet)
- 📊 Confidence Score & Reports

### Tech Stack
Frontend: React, Leaflet.js, Tailwind CSS
Backend: Python, FastAPI
AI/ML: TensorFlow, Scikit-learn
Data: Sentinel-2, USGS, GSI
